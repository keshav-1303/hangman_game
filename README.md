# Hangman Game in Pygame

This is a simple Hangman game built using the Pygame library. The player clicks on letter buttons to guess a hidden word, and loses after 6 incorrect guesses.

## Features

- Interactive letter buttons
- Word selection from a `words.txt` file
- Visual hangman progression using images
- End screen with win/loss message

## Requirements

- Python 3.x
- Pygame (`pip install pygame`)
- A `words.txt` file with a list of words (one per line)
- Hangman images: `hangman0.png` to `hangman6.png` in the same directory

## How to Run

1. Make sure you have all dependencies installed:
    pip install pygame

2. Add a `words.txt` file in the same directory:

3. Run the game:
    python hangman.py

## Controls

- Click on the letters to guess.
- Press any key to restart after winning or losing.
- Press `ESC` or close the window to quit.

Enjoy playing!
